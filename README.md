# Portofolio Personal (Vite + React + Tailwind v4 + Framer Motion)

## Jalankan lokal
npm install && npm run dev

## Deploy ke Vercel
Push ke GitHub → vercel.com → Add New Project → Deploy (Vite terdeteksi otomatis).

## Kustomisasi
- Semua data (profil, pendidikan, skill, organisasi, project, hobi): src/data.js
- Foto: public/profile.jpg, public/projects/p1.jpg..., public/hobbies/h1.jpg... ; CV: public/cv.pdf
- Form kontak: isi formEndpoint (mis. Formspree) di src/data.js
